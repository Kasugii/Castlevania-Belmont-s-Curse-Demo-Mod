Your real save is protected

The mod never modifies your original save. Here is how it works:

  • On the first launch, the mod makes a copy of your saves into a separate folder called DemoTweaks_Saves.
  • While the mod is installed, the game only reads and writes that copy. Everything you do with the mod (F4 items, outfits, relics, abilities…) stays in it.
  • Remove the mod (or just turn it off, see below) and the game reads your original save again, untouched. No risk for when the full game comes out.
  • Steam achievements are blocked while the mod is active, so nothing gets unlocked by cheating.

  • Weapons, spells, relics and abilities (double jump, dash…).

  • Leon — replayable, straight back to the mirror after the win (no cutscene).
  • Leon HARDCORE — the Unchained Lion: faster, meaner, a BERSERK phase and a LAST BREATH comeback. Dies? He stays hardcore until you beat him.
  • Paranthropus — replayable arena, back to the mirror when he falls.
  • Teleport to the Mirror of Life at any time.

Install — step by step

Takes 2 minutes. Everything is included (BepInEx + the mod), nothing else to download.

1

Download the archive

Download Castlevania Belmont's Curse Demo Mod.zip with the button at the top of this page.

2

Extract it

Right-click the archive → Extract all (or use WinRAR / 7-Zip). You get a folder with the same name.

Inside, you should see 5 items: dotnet, BepInEx, .doorstop_version, doorstop_config and winhttp.dll.

3

Open the game folder

In Steam: right-click Castlevania: Belmont's Curse Demo → Manage → Browse local files. It usually is:

C:\Program Files (x86)\Steam\steamapps\common\Castlevania Belmont's Curse Demo
4

Copy the 5 items into the game folder

Select all 5 items from the extracted folder, copy them (Ctrl+C)…

…and paste them (Ctrl+V) in the game folder, right next to Castlevania Belmont's Curse Demo.exe.

Don't put them in a sub-folder: winhttp.dll must be in the same folder as the game's .exe.
5

Launch the game from Steam

That's it! Load your save and press F1, F3, F4 or F5.

The very first launch can take a bit longer while BepInEx prepares its files (it can take 2–3 minutes again if the demo gets updated). Just wait, it's normal — the next launches are fast.

Inside the BepInEx folder, the mod itself lives in BepInEx\plugins\BelmontsCurse.DemoTweaks:

Turn the mod off / uninstall

Turn it off (to play on your real save)

Just move BelmontsCurse.DemoTweaks.dll out of BepInEx\plugins\BelmontsCurse.DemoTweaks — for example one folder up, into BepInEx. The game then loads your original save. Put the file back to get your modded game back.

Uninstall completely

Delete the 5 items you copied (dotnet, BepInEx, .doorstop_version, doorstop_config, winhttp.dll) from the game folder. Your original save is untouched.

FAQ

The game doesn't change / the keys do nothing

Check that the 5 items are directly in the game folder (next to the .exe), not in a sub-folder, and that you launched the demo from Steam. Then load a save before pressing the keys.

The first launch is very long

Normal: BepInEx prepares its files once (2–3 minutes max). Don't close the game.

I want my modded game to start from my current real progress again

Delete the DemoTweaks_Saves folder (see Your save). The mod will make a fresh copy on the next launch.

Is it safe for my Steam account?

It's a single-player demo and the mod blocks achievements while it is active. Your real save is never modified.
